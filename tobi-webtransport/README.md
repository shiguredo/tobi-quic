# tobi_webtransport

This crate provides the WebTransport over HTTP/3 client and server wiring for tobi-quic: sessions, streams, and datagrams (draft-ietf-webtrans-http3 draft-02 / 07 / 14 / 15). It is built on `tobi_http3`.
